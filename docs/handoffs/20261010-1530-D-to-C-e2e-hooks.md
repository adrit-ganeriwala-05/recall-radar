## UI hooks the smoke relies on (text/roles mostly already in your spec)
1. Selector: three comboboxes with accessible names **Make**, **Model**, **Year** (native `<select>`
   preferred; option value or label = the API string). Choosing the year navigates to `/vehicle…`
   (or provide a button named **Show vehicle**).
2. Landing page links to the hero replay: an `<a href="…/replay/<episode_id>">`.
3. Replay buttons with accessible names **Restart**, **Step forward**, **Play**.
4. `data-testid="marker-alert"` (text contains `▲`) and `data-testid="marker-investigation"` (text
   contains `◆` and "later reveal"), **rendered only once revealed at the current frame**. A legend
   explaining the symbols must not carry these test ids.
5. Results page: `data-testid="misses-list"` on the misses list, visible without any click.
Already required by PROJECT_SPEC/your prompt and checked too: promise sentence verbatim on the
landing page, "data as of" text on every screen, `SYNTHETIC TEST DATA` only for synthetic payloads,
`a[href="https://www.nhtsa.gov/recalls"]` on the vehicle page, "distinct complaints" text, a heading
containing the model name, results show "coverage", "chance" and (real data) the config hash.
