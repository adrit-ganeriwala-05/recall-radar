## Behaviour C relies on
- Errors: `ErrorResponse`; 400 `invalid_parameter` (missing/invalid query, `page < 1`,
  `page_size` outside 1–100, bad `period`, bad id format), 404 `not_found` (unknown make/model/
  vehicle/group/episode/replay, unknown `/api/*` path), 503 `unavailable` (DB not built,
  results/hero/CSV not exported), 500 `internal` (malformed export; no traceback leaks).
- `Cache-Control: public, max-age=3600` on every 200; errors and `/healthz` are `no-store`.
- `VehicleResponse.monthly`: vehicle-level counts by availability month, contiguous; `score` is
  always null and `alert` always false there — alerts live on components and the issue page.
  The month after the data cutoff is `partial`. `sum(monthly) == distinct_complaints`.
- Components include `UNKNOWN OR OTHER` (counted, never a detector group, never has episodes).
- `IssueResponse.evidence`: all complaints of the group (repeats included, flagged `dup_text`),
  ordered `avail_date, odino`; `total == group.distinct_complaints`. With `episode_id` it is the
  episode's 2-month window without repeats, so `total == window_count` (checked on all 2,532
  episodes of a full B pipeline run). `series` counts repeats once, like the detector.
- `excerpt` ≤ 400 characters, already redacted; ends with `…` when cut.
- Query values are case- and space-insensitive and go through the alias table
  (`model=c 300` → `C300`).
