## Entrypoints
- Python service: `uv run uvicorn recall_radar.messaging.app:app --host 127.0.0.1 --port 8791`
  (`POST /spectrum-webhook`, `GET /healthz`). Never imported by `recall_radar.api` (test).
- Monitor (daily, one run at a time via the SQLite lock): call `recall_radar.messaging.monitor.run(con, nhtsa_fetch)`
  then `outbox.process(con, SidecarProvider())` — a 10-line CLI wrapper is the D-side timer's job (or ask A).
- Sidecar (TypeScript, Photon SDK): `recall_radar/messaging/photon_ts/` — not installed; see its README.

## Environment
| Var | Meaning |
| --- | --- |
| `RR_MESSAGING_ENABLED` | `1` to process webhooks; default `0` = every request 503, nothing stored (kill switch) |
| `IMESSAGE_WEBHOOK_SECRET` | per-webhook signing secret from the Spectrum dashboard (shown once) |
| `RR_DATA_DIR` | holds `messaging.sqlite` (WAL) |

| `PROJECT_ID`, `PROJECT_SECRET` | sidecar only (Photon project credentials) |

## systemd needs
Two loopback-only units (messaging app, sidecar) + one daily timer for the monitor; Caddy routes only
`/spectrum-webhook` to :8791 (HTTPS required by Photon for webhooks). Outbound network is needed for
api.nhtsa.gov (monitor) and Photon (sidecar) — unlike the analysis API, so do not reuse its IPAddressDeny unit.

## What exists (mock-verified, `tests/messaging/`, 25 tests)
HMAC v0 signature + 5-min window + size cap + webhook-id dedupe; echoes ignored; group chats refused; enrollment
only via WATCH + explicit YES (consent names vehicle, ≤ 1/day, quiet hours 21:00–08:00 tz, STOP); one vehicle
per subscriber; no phone numbers as arguments; HELP/WATCH/STATUS/DETAILS/WHY/PAUSE/RESUME/STOP (cancels queued)/
DELETE (rows removed, route tombstoned against late events); outbox idempotency, STOP recheck before every
send, ≤ 1 digest/day, quiet hours, retries ≤ 3, 'uncertain' never resent; monitor seeds silently, diffs by
ODINO/campno, corrections and removals classified, catch-up label; fixed alert template from the payload;
conversation intents (fixed list), allowlisted tools ≤ 3 calls, numbers validated against tool output, VIN →
official handoff, no diagnosis, retrieved text never obeyed, router failure → keywords, 30-min context.
